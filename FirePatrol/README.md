FirePatrol

FirePatrol is an AI-powered wildfire monitoring and response support system designed for real-time surveillance and predictive analysis.

Platform: Fire Monitoring Dashboard
	•	Provides a centralized dashboard for monitoring CCTV feeds from mountains nationwide.
	•	When a wildfire is detected, the system automatically:
	•	Highlights the affected region’s CCTV footage.
	•	Displays real-time wildfire spread predictions, including:
	•	Direction and speed of spread.
	•	Timeline of progression.
	•	Visual overlays of spread stages.

Wildfire Detection Model
	•	Utilizes AI to analyze live CCTV footage.
	•	Detects early signs of wildfire such as smoke and flames with high accuracy.

Wildfire Spread Prediction System
	•	Predicts how and where the fire will spread using AI.
	•	Takes into account:
	•	Wind direction/speed
	•	Terrain slope and elevation
	•	Fuel type and distribution

Status

This project is actively being developed and tested with real-world CCTV data and environmental conditions.
